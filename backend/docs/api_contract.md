
# API Contract

Base URL: http://localhost:8000

All request and response bodies use JSON.

## 1. GET /health

Response: 200

{
  "status": "ok",
  "keys_configured": 2,
  "cache_enabled": true
}

## 2. POST /chat

Request:

{
  "session_id": "s-7f3a",
  "message": "What is the capital of France?",
  "system_prompt": "You are a helpful assistant."
}

system_prompt is optional.

Response: 200

{
  "session_id": "s-7f3a",
  "reply": "The capital of France is Paris.",
  "metadata": {
    "resolution_source": "LIVE_INFERENCE",
    "model": "gemini/gemini-3.8-flash",
    "latency_ms": 812,
    "input_tokens": 42,
    "output_tokens": 9,
    "key_id": "key_1",
    "fallback_attempts": 0
  }
}

## 3. GET /sessions/{session_id}/messages

Response: 200

{
  "session_id": "s-7f3a",
  "messages": [
    {
      "role": "user",
      "content": "What is the capital of France?"
    },
    {
      "role": "assistant",
      "content": "The capital of France is Paris.",
      "metadata": {
        "resolution_source": "LIVE_INFERENCE",
        "input_tokens": 42,
        "output_tokens": 9
      }
    }
  ]
}

## Error Responses

422: Invalid request
503: All providers unavailable
404: Session not found

All errors must return JSON containing a detail field.

Failed requests must not be persisted.

## Failure Simulation

Request header:

X-Simulate-Failure: key_1=429

Expected:
- key_1 fails
- key_2 handles the request
- HTTP 200

Request header:

X-Simulate-Failure: *=429

Expected:
- Every key fails
- HTTP 503
- No message persistence

## Cache Behaviour

- Cache key = model + complete LLM message list.
- Identical first message across sessions should hit cache.
- Cache hit returns identical reply.
- resolution_source = LLM_CACHE.
- key_id = null on cache hits.

## Session Behaviour

- Session ID is generated by the frontend.
- New page load generates a new session.
- Backend stores conversation history in SQLite.
- Client sends only the latest message.
- Backend retrieves previous messages.
- History endpoint returns messages oldest first.
- System prompt is not included in returned history.
